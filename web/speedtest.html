🚀 CF 优选域名测速

在你当前这台设备、当前这条宽带上实测各候选域名的延迟，挑出最快的几个， 一键生成 EDGE_HOSTS 配置。
  1. （可选）点「加载公开优选域名列表」，或把你自己的候选粘进文本框，每行一个
  2. 点「开始测速」，等跑完
  3. 点「复制配置」，粘贴到 vpngate.py 的 EDGE_HOSTS 里，提交后重跑 Actions

1️⃣ 候选域名 （每行一个，支持 domain 或 domain:port，# 后面是备注会被忽略）

公开列表来自 GitHub 社区维护（svip-s/cloudflare_ip），加载后会自动去重追加。你也可以把 bestcf 等站挑的域名手动粘进来。

2️⃣ 测速参数

⚠️ 测速时请关闭代理 / VPN，否则测出来的是代理服务器的速度，不是你直连 Cloudflare 的真实延迟。
